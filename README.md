# Instagram Scraper

A tool for searching and browsing your own exported Instagram data — built because Instagram's native search is limited and hard to use for things like finding old DMs, posts, or saved content.

> 🚧 Work in progress — backend is being built out, frontend to follow.

## What it does

- Takes your Instagram data export (the ZIP/JSON Instagram gives you on request)
- Parses and indexes it for fast, flexible search
- Aims to provide a better search experience than Instagram's own in-app search

## Tech Stack

- **Backend:** Node.js, Express
- **Frontend:** (planned)
